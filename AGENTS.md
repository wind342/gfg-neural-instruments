# Scope

This is an independent extraction. The original research-evidence and structural
Core repositories are read-only authorities. Do not modify their files, tags or
history. Do not push or publish without an explicit user request.

Preserve frozen measurement definitions; identify semantic corrections by version.
Keep model/task/optimizer bindings outside measurement formulas. Unknown is not
zero or false. Tests must include real native execution, identity failures, state
isolation, numerical recomputation and Core v3 validation. Do not claim historical
reproduction when historical artifacts are absent.
